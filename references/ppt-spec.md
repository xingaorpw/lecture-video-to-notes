# 课件规格：`slides.json` 与授课节奏

## 1. 目标

PPT 不是讲义的缩略版，而是**上课时用的视觉骨架**：

- 一页只推进一个结论；
- 标题就是结论，学生扫一眼知道这页要说什么；
- 正文是支撑点，不是讲稿全文；
- 讲稿放 `notes`，放映时看不见，老师自己看；
- 公式、表格、对比图优先于大段文字。

## 2. 页数与时序

90 分钟课建议 25–40 页。计算公式：

```text
目标页数 = max(15, min(45, round(时长分钟 / 4)))
```

校验下限按同一公式；上表的 25–40 页是创作目标，长课不要为了凑页数灌水。

| 时长 | 页数 | 结构 |
| --- | --- | --- |
| 45 min | 15–20 | 封面 + 路线 + 3 章 + 小结 |
| 90 min | 25–40 | 封面 + 路线 + 4–6 章 + 例题 + 小结 + 任务 |
| 120 min | 35–45 | 6–8 章，每章 3–5 页 |

章节页不计入“内容页”，但计入总页数。

## 3. 顶层结构

```json
{
  "meta": {
    "course": "线性代数",
    "lecture": "第03讲 矩阵乘法",
    "instructor": "张老师",
    "duration": "92 min",
    "source": "课堂录播",
    "theme": "academic-blue"
  },
  "slides": []
}
```

`meta` 必填：`course`、`lecture`。`theme` 目前只支持 `academic-blue`，留空即默认。

## 4. 幻灯片类型

### 4.1 `title` 封面

```json
{
  "type": "title",
  "title": "矩阵乘法",
  "subtitle": "从行列视角到复合变换",
  "notes": "开场 30 秒：先问学生，矩阵乘法为什么不是对应元素相乘。"
}
```

### 4.2 `agenda` 路线

```json
{
  "type": "agenda",
  "title": "本讲路线",
  "items": [
    "为什么需要矩阵乘法",
    "定义与行列视角",
    "几何意义：复合变换",
    "运算性质与易错点",
    "例题与小结"
  ],
  "notes": "用 1 分钟把路线串一遍，告诉学生第 3 部分是难点。"
}
```

### 4.3 `section` 章节页

```json
{
  "type": "section",
  "title": "二、定义与行列视角",
  "subtitle": "左行右列，逐元素内积",
  "notes": "过渡：从‘为什么’进入‘怎么算’。"
}
```

### 4.4 `content` 内容页

```json
{
  "type": "content",
  "title": "矩阵乘法是线性组合的批量写法",
  "bullets": [
    "左矩阵的每一行，对右矩阵的行做线性组合",
    "结果的第 i 行第 j 列 = 左第 i 行 · 右第 j 列",
    "维度条件：左列数 = 右行数",
    "不满足交换律：AB ≠ BA"
  ],
  "notes": "先讲维度条件，再用手算 2×2 例子。停顿问：为什么不是对应元素相乘？"
}
```

限制：`bullets` ≤ 6 条，每条 ≤ 30 个中文字符（公式/英文可放宽）。超过就拆成两页，标题加“（续）”。

### 4.5 `two_col` 双栏对比

```json
{
  "type": "two_col",
  "title": "行列视角与变换视角",
  "left": {
    "heading": "行列视角",
    "bullets": ["结果元素 = 行与列的内积", "适合手算", "强调计算规则"]
  },
  "right": {
    "heading": "变换视角",
    "bullets": ["矩阵 = 线性变换", "乘法 = 复合变换", "强调几何意义"]
  },
  "notes": "左右各讲 1 分钟，最后合起来：两种视角是同一件事。"
}
```

每栏 ≤ 4 条，每条 ≤ 22 字。

### 4.6 `formula` 公式页

```json
{
  "type": "formula",
  "title": "乘法定义",
  "formula": "$$(AB)_{ij}=\\sum_{k=1}^{n} a_{ik}b_{kj}$$",
  "explain": [
    "A 是 m×n，B 是 n×p，结果 C 是 m×p",
    "i 锁定 A 的行，j 锁定 B 的列",
    "k 是求和指标，也是维度条件"
  ],
  "notes": "先遮住公式，让学生说维度；再逐项解释 i、j、k。"
}
```

`formula` 用 LaTeX，生成器会渲染成图片；渲染失败时以等宽文本显示，不能留空。

### 4.7 `table` 表格页

```json
{
  "type": "table",
  "title": "三种运算对比",
  "headers": ["运算", "维度要求", "交换律", "典型用途"],
  "rows": [
    ["加法", "同型", "满足", "线性组合"],
    ["乘法", "左列=右行", "不满足", "复合变换"],
    ["转置", "任意", "—", "内积/对偶"]
  ],
  "notes": "让学生先填‘交换律’一列，再揭示答案。"
}
```

最多 6 列、8 行（含表头）；单元格 ≤ 18 字。超了拆表。

### 4.8 `quote` 原话/强调

```json
{
  "type": "quote",
  "title": "老师强调",
  "quote": "矩阵乘法不满足交换律，这是它和实数乘法最不一样的地方。",
  "source": "[00:35:10]",
  "notes": "放慢语速，重复一遍；提醒学生记到易错点。"
}
```

### 4.9 `summary` 小结

```json
{
  "type": "summary",
  "title": "本讲小结",
  "bullets": [
    "乘法 = 行与列的内积 = 复合变换",
    "先检查维度，再动手算",
    "不满足交换律，但满足结合律",
    "det(AB)=det(A)det(B)"
  ],
  "notes": "用 2 分钟收束，留 1 分钟提问。"
}
```

### 4.10 `end` 结束页

```json
{
  "type": "end",
  "title": "谢谢",
  "subtitle": "课后任务：完成讲义第 3 章自测 1–5 题",
  "notes": "布置作业，提醒下节课带习题本。"
}
```

## 5. 讲稿 `notes`

- 每个内容页/章节页/公式页/表格页都必须有 `notes`。
- 80–200 个中文字符，写“怎么讲”，不是“这页写了什么”。
- 至少包含一个动作：停顿、提问、举例、让学生计算、强调易错点。
- 不要写“这一页介绍了……”；写“先问……，再……，最后……”。

示例：

> 先不急着给公式，问学生：两个 2×2 矩阵相乘，为什么不是对应元素相乘？停 10 秒。再用手算例子说明“左行右列”，最后回到维度条件。

## 6. 设计系统

主题：`academic-blue`

| 角色 | 色值 | 用法 |
| --- | --- | --- |
| 深海军蓝 | `#0F2742` | 封面/章节页背景、主标题 |
| 学术蓝 | `#2E86DE` | 强调线、章节编号、链接 |
| 暖金 | `#F2B84B` | 重点数字、公式高亮、警示 |
| 浅灰蓝 | `#F7F9FC` | 内容页背景 |
| 正文黑 | `#17212B` | 正文 |
| 次级灰 | `#5B6B7C` | 页脚、注释 |

字体：中文 `Microsoft YaHei`，英文 `Arial`；标题加粗，正文常规。

版式：

- 16:9，13.333 × 7.5 英寸。
- 内容页：顶部 0.12" 蓝色强调条；标题距顶 0.42"；正文距顶 1.55"。
- 页脚：左侧课程/讲次，右侧页码；细分隔线。
- 章节页：深色背景，大号章节数字，标题居中偏左。
- 封面：深色背景，主标题 40–44pt，副标题 20pt，底部课程信息。
- 内容页正文 18–22pt；表格 12–14pt；公式图高度不超过 3.2"。

## 7. 内容规则

1. **标题是结论**：`矩阵乘法是线性组合的批量写法`，不是 `矩阵乘法的定义`。
2. **一页一个动作**：讲一个概念、做一个例题、完成一次对比；不要一页塞三件事。
3. **公式页必须解释符号**：`explain` 至少 3 条，包含维度条件。
4. **表格页必须能提问**：至少有一个单元格是学生可以先猜/先填的。
5. **例题页**：题目、思路、步骤、答案、易错点，至少出现 3 项；不要只放答案。
6. **每章至少 1 个例题/证明页**；纯概念章至少 1 个反例页。
7. **不编造老师原话**：`quote` 必须来自逐字稿，带时间戳；没有原话就用 `content`。
8. **不讲义原文搬家**：一页正文超过 6 条或 180 字，拆页或改双栏。
9. **页脚信息**：生成器自动加，不用写进 `title`。
10. **结尾留任务**：至少一页课后任务/思考题，和讲义自测题对应。

## 8. 交付前自检

- [ ] 页数在目标区间。
- [ ] 封面、路线、章节页、内容页、小结、结束页齐全。
- [ ] 每页标题是完整结论句。
- [ ] 内容页 ≤ 6 条，每条 ≤ 30 字。
- [ ] 每个内容页有 `notes`，且是“怎么讲”。
- [ ] 公式页有 `formula` + ≥ 3 条 `explain`。
- [ ] 表格 ≤ 6 列、≤ 8 行。
- [ ] 没有空白页、没有“TODO”。
- [ ] 至少 1 个例题/证明页，至少 1 个易错点页。
